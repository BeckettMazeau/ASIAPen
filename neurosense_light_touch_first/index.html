How to calibrate

Select a sensory cell, then choose Draw new region to click around the matching anatomy. Finish drawing closes the polygon. Edit corners lets you drag vertices; double-click an edge to add a vertex, or right-click a vertex to remove it. Draw new region adds another separate area to the selected dermatome. Use Region to choose which area to move or reshape. Move testing dot drags the dot independently. All changes save automatically.

Outlines are user-editable visual annotations, not verified clinical dermatome boundaries.
