NeuroSense sensory worksheet - editable dermatome shapes

Open index.html in Chrome or Edge. Keep worksheet.png beside index.html.
Choose a sensory cell. Outline tool > Draw new region: click around the anatomical area, then Finish drawing.
Outline tool > Edit corners: drag white handles, double-click an edge to add a handle, right-click a handle to delete it.
Outline tool > Move region: drag the region. Reset this region restores its initial approximate polygon.
Export outlines saves a JSON backup; Import outlines restores one.
Shape changes are saved in browser localStorage. The anatomy is not clinically validated.
Scores 0/1/2 remain available with keyboard and on-screen controls.
